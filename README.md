# 🎧 SoundProfile

Uma rede social para compartilhar gostos musicais, avaliar álbuns e artistas e descobrir novas músicas.

### 🛠️ Tecnologias
- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL

### 🚀 Como executar

```bash
npm install
npm run dev
```

Configure o arquivo `.env.local` com a variável `DATABASE_URL` para conectar ao PostgreSQL antes de executar as funcionalidades que dependem do banco.
